## V3.0：视频素材分辨率计算
- 独立的“视频素材分辨率”模式，可输入同尺寸墙面数量、每面墙投影机数量、横投/竖投方向、融合重叠率。
- 根据单通道原生分辨率计算单面墙的理论有效素材画布。
- 计算多面墙线性展开后的理论画布、宽高比与总像素量。
- 在“按墙面尺寸反推”模式中，自动对比横投/竖投方案对应的素材分辨率。
- 支持复制参数或下载 TXT 说明，便于销售直接转发给视频制作公司。

## V2.0：按墙面尺寸反推选型
- 可输入相同尺寸的墙面数量（1–6面）、墙宽、墙高。
- 可输入实际投影机投射比；不绑定具体投影机型号。未输入投射比时，仍显示数量、画面尺寸和融合级联，但不显示投射距离。
- 同时比较横投与竖投方案。
- 自动估算每面墙投影机数量、单台画面尺寸、墙宽/墙高覆盖率、融合重叠、相邻画面中心间距、理论镜头距离。
- 自动计算总输出通道、融合单元数量及级联组合（如 2+1、2+2+2）。
- 支持选择单通道输出分辨率：1920×1080 或 1920×1200。

## 原有功能
- 按应用场景快速配置：单面超宽屏、L形双墙、U形三面墙、四面墙、四面墙+地面、六面空间、自定义投影面。
- 按总通道数直接选型，支持 1–32 路。
- 每路投影机对应一路融合输出。
- 自动生成级联组合：1路为 `1`、2路为 `2`、3路为 `2+1`、4路为 `2+2`、5路为 `2+2+1`、6路为 `2+2+2`，以此类推。
- 线性画布分辨率估算。
- 支持手机浏览器访问、添加到主屏幕及离线使用（首次访问需联网）。

## 视频素材分辨率的计算假设
- 横投时，单通道画布宽高按选择的原生分辨率；竖投时假设画面旋转90°并交换宽高。
- 相邻画面重叠像素 = 单通道在拼接方向上的像素宽度 × 重叠率；单面墙只有一台投影机时不计算拼接重叠。
- 单面墙逻辑素材画布宽度 = 每面墙投影机数量 × 单通道像素宽度 −（投影机数量−1）× 重叠像素。
- 多墙展开画布按各面墙同尺寸、同配置并线性首尾展开估算，不包含墙角几何补偿、不同墙面尺寸差异、额外裁切或映射修正。
- 该结果是理论有效素材画布，不保证等于播放服务器输入分辨率、视频编码分辨率或输出时序。必须和融合软件、播放服务器及内容制作流程共同确认。

## 尺寸反推的计算假设
- 同一项目中输入的墙面尺寸相同，每面墙采用相同投影机数量；若墙面尺寸不同，应逐面分别计算。
- 横投画面比例按所选分辨率的宽高比；竖投按画面旋转90°后的比例计算。
- 多机拼接时，默认按单幅画面宽度的设定百分比估算重叠；目标覆盖率可选90%、95%或100%。若理论覆盖宽度超过墙宽，程序按比例缩小画面，尽量避免超出墙边。
- 理论镜头距离按“实际画面宽度 × 输入投射比”计算。该值不等于最终吊装定位尺寸，也不自动考虑镜头偏移、变焦范围、机身尺寸或障碍物。
- 设备数量较少的方案仅作为预算基准，不代表其画面效果、亮度均匀性、安装条件或内容适配一定更优。
- 超过32路输出时应单独进行工程核算。

## 融合级联规则
本工具不绑定具体融合器型号。1路或2路输出均按一个融合单元计算；超过2路时优先按双通道分组，若剩余1路则由最后一个单元承载1路输出。

## 部署方式
1. 建议在 GitHub 账号下新建独立仓库（例如 `sipa-fusion-calc`），不要覆盖现有 `sipa-calc` 投影机计算器仓库。将本目录所有文件上传到新仓库根目录。
2. 使用 GitHub Pages 时，在仓库 Settings → Pages 中选择从分支部署，并将目录设为根目录 `/`。
3. 发布后通过 HTTPS 地址访问。
4. 手机浏览器打开网址，选择“添加到主屏幕”或“安装应用”。
5. 首次访问需要联网，成功打开后可缓存核心页面供离线使用。

## 注意事项
计算结果仅为理论粗算，不是施工图或最终媒体服务器配置。必须现场复核实际投射比与变焦范围、投影机竖装及散热要求、镜头距离、机身和吊架空间、融合器旋转映射能力、画面内容比例、重叠区域及遮挡条件。实际接口、级联方式、同步要求和播放系统能力以最终产品规格与项目设计为准。


## 级联素材建议的使用边界
上述参数用于制作起点和现场对照测试，不是厂家认证或零卡顿、无缝切换、帧精确同步承诺。4K 参数为阶段测试候选值；1920×1200 样机及不同型号、固件和播放路径应分别验证。
